# בוזוקי אקדמי — Μπουζούκι

כלי לימוד אינטראקטיבי לבוזוקי יווני 8 מיתרים (טטראחורדו, כיוונון C-F-A-D).

## מאסטר מודוסים

משחק אינטראקטיבי ללמידת דרומוסים (סולמות יווניים) בזמן אמת. בחרו דרומוס, טוניקה ורמת קושי — האפליקציה מנגנת את הסולם, מאירה כל תו על גריף 8 מיתרים, ומקשיבה למיקרופון כדי לבדוק שניגנתם נכון.

- **תו אחר תו** — שמעו, ראו על הגריף, נגנו
- **סולם מלא** — כל הסולם מוצג, נגנו ברצף
- **Hero Mode** — תווים נופלים בסגנון Guitar Hero
- 12 דרומוסים יווניים ומאקאמים
- 3 רמות קושי

![מאסטר מודוסים — בחירת דרומוס וגריף](screenshots/master-modes.jpg)

## מאסטר אקורדים

למדו אקורדים על הבוזוקי — האפליקציה מראה את צורת האצבוע על הגריף, משמיעה את האקורד, ומקשיבה לנגינה שלכם. מזהה כל תו שנוגן ונותנת משוב בזמן אמת.

- 17 אקורדים: יווניים, מזרחיים (מקאמים)
- צ'יפס צבעוניים לכל תו באקורד (ירוק = זוהה)
- טיימר לפי רמת קושי
- גריף 8 מיתרים עם סימון צורת האקורד

## למד מהשיר — Bouzouki 2.0

מסך **למידה · חדש** בתפריט (ראשון):

| מסך | מה עושים שם |
|---|---|
| **למד מהשיר (YouTube)** | נגן YouTube, נתיבי דרומוס (ζεϊμπέκικο ועוד), משאבי רשת, **ניתוח AI** |
| **התקדמות** | גרף פעילות 14 יום, streak, XP — נשמר ב-IndexedDB |
| **ניתוח AI** (טאב) | MP3/YouTube → BPM, אקורדים, TAB, waveform, A/B loop, האטה עם pitch, זיהוי אקורד חי |

### ניתוח שיר — מה עובד בלי שרת

- העלאת **MP3/WAV** — Essentia.js בדפדפן
- **Play-along** — תרגול TAB במאמין עם כוכבים ו-XP
- **Tooltip אקורד** — ריחוף על אקורד בכל האפליקציה

### YouTube + הפרדת stems (אופציונלי)

1. העתיקו `config.example.js` → `config.js` והגדירו `stemProxyUrl: 'http://localhost:3456'`
2. הריצו את הפרוקסי:
   ```bash
   cd tools/stem-proxy
   npm install
   npm start
   ```
3. **YouTube:** התקינו [yt-dlp](https://github.com/yt-dlp/yt-dlp) (`pip install yt-dlp` / `winget install yt-dlp`)
4. **Stems:** הוסיפו `LALAL_LICENSE_KEY` או `MOISES_API_KEY` ב-`tools/stem-proxy/.env`

מדריך מלא גם בתוך האפליקציה: **למד מהשיר** → **מדריך התקנה**.

### ייצוא ו-PWA

- **ייצוא JSON / TXT** — אחרי ניתוח, כפתורי הורדה בתוצאות
- **נתח מ-YouTube** — כפתור "נתח ב-AI" בטאב YouTube
- **PWA** — `manifest.json` + service worker; cache לכל JS/CSS + **Essentia.js** ו-**Meyda** מה-CDN (offline חלקי אחרי ביקור ראשון)

### תוכן ζεϊμπέκικο

- תרגילים **zb1–zb10** (9/4, טקסימי, Am–Dm–E7, סגנון Ευδοκία)
- **נתיב ζεϊμπέκικο** מורחב — 9 שלבים + 7 שירים עם YouTube
- משאבי רשת: Ευδοκία, ספירת 9/4

## איך מפעילים

פשוט פותחים את `index.html` בדאבל-קליק — אין צורך בהתקנה, באינטרנט או בשרת.
(מומלץ Chrome / Edge. בכניסה הראשונה ללחוץ פעם אחת בעמוד כדי לאפשר שמע.)

**במובייל:** הממשק מותאם מלא לטלפון (ניווט תחתון, כפתורי מגע). העלו לשירות סטטי חינמי (Netlify Drop / Vercel) וקבלו כתובת שנפתחת מכל מקום.
