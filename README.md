# בוזוקי אקדמי — Μπουζούκι

כלי לימוד אינטראקטיבי לבוזוקי יווני 8 מיתרים (טטראחורדו, כיוונון C-F-A-D).

## מאסטר הפנייה — משחק נפרד

תיקייה **`penia-master/`** — אפליקציה עצמאית לשיווק בקבוצות:
- פרופילי שחקנים + לוח תוצאות
- 8 שלבים עם נעילה/פתיחה
- שיתוף ציון לוואטסאפ
- סטטיסטיקות קהילה (Firebase אופציונלי)

פתחו `penia-master/index.html` או פרסמו את התיקייה בנפרד.

## איך מפעילים

פשוט פותחים את `index.html` בדאבל-קליק — אין צורך בהתקנה, באינטרנט או בשרת.
(מומלץ Chrome / Edge. בכניסה הראשונה ללחוץ פעם אחת בעמוד כדי לאפשר שמע.)

**במובייל:** הממשק מותאם מלא לטלפון (ניווט תחתון, כפתורי מגע). כדי להשתמש בנייד — העתיקו את התיקייה לטלפון ופתחו את `index.html` ב-Chrome, או העלו את התיקייה לשירות סטטי חינמי (למשל Netlify Drop) וקבלו כתובת שנפתחת מכל מקום.

## מה יש בפנים

| מסך | מה עושים שם |
|---|---|
| **הכלי והכיוונון** | טיונר עם צלילי ייחוס אמיתיים (כולל זוגות אוקטבה), איור מבנה הכלי, מפת כל הצלילים על לוח הסריגים |
| **דרומוסים** | 15 דרומוסים (חיג'אז, אוסאק, סבאח, ראסט, חוזאם, קרציגאר, סוזינאק, ניקריז...) — לוח סריגים אינטראקטיבי, השמעת הסולם, צליל רקע לטקסימי, תרגיל מיתר בודד, תיאוריה וטיפים. בנוסף: מדור מאקאם — ששת הג'ינס (אבני הבניין) עם השמעה, וטבלת "מתכונים" דרומוס = ג'ינס תחתון + עליון |
| **פנייה — יד ימין** | מדריך טכניקה מאויר + מאמן פנייה מונפש: תבניות למטה/למעלה, טריולים, טרמולו — עם מטרונום מובנה |
| **ספריית תרגילים** | 59 תרגילים ב-12 קטגוריות (כולל איצבוע יד שמאל עם מספרי אצבעות על ה-TAB) במבנה המתודיקות היווניות: יסודות פנייה, מעברי מיתרים, טריולים, טרמולו, סולמות, סקוונצות, מסעות בין מיתרים (בריולאז', פדל, ארפז'ים), טכניקות מעולם העוד (רישה, בס-מלודיה, פרצים), הבאגלמה/סאז (טרמולו אקורדי, טזנה 9/8 ו-7/8), הגיטרה (sweep, פיקינג כלכלי, 3 תווים למיתר), ופריטה+אקורדים עם 26 צורות אקורדים |
| **מקצבים יווניים** | זאימבקיקו 9/4, חסאפיקו, ציפטטלי, קלמטיאנוס 7/8 ועוד — מכונת מקצב דום/טק עם הנפשה, פנייה מומלצת לכל מקצב |
| **מאסטר הפנייה** | משחק קצב דו-כיווני: חיצים ↓↑ זורמים אל קו פגיעה, מקישים במקלדת (↓/↑ או J/K) או במגע — 8 שלבים מדורגים מרבעים ועד טזנה 7/8, חלונות שיפוט מקצועיים (מושלם ±50ms, טוב ±110ms), ניקוד, קומבו, כוכבים, שיאים אישיים וכיול תזמון אישי |
| **מאמן מאזין** | הכלי מקשיב לנגינה דרך המיקרופון, מזהה כל צליל (autocorrelation pitch detection), בודק מול היעד צליל-אחר-צליל עם סימון ירוק/אדום, נותן ציון, משוב מדורג ובדיקת יציבות קצב — וגם מד-כוונון חי עם מחט סנטים |
| **חדר תרגול** | שגרת אימון יומית עם מעקב התקדמות (נשמר במחשב), מטרונום חופשי, עצות זהב |
| **מילון רבטיקו** | המונחים החיוניים — מטקסימי ועד מאנגאס |

## קבצים

- `index.html` — מבנה האפליקציה
- `css/style.css` — עיצוב
- `js/data.js` — הידע המוזיקלי (דרומוסים, מקצבים, תבניות) — קל להרחבה!
- `js/audio.js` — מנוע צליל (סינתזת מיתר פרוט, מטרונום)
- `js/app.js` — הלוגיקה והאינטראקציה

כל הצלילים מסונתזים בזמן אמת ב-Web Audio — בלי קובצי שמע.
