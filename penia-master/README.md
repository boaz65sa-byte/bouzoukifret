# בוזוקי מאסטר | Bouzouki Master

משחק לימודי עצמאי לתרגול **פנייה**, **דרומוסים** ו**אקורדים** על בוזוקי יווני — מושלם לשיתוף בקבוצות, שיעורים ווואטסאפ.

**קישור חי:** [penia-master.vercel.app](https://penia-master.vercel.app)

**אקדמיה מלאה:** [בוזוקי אקדמי](https://boaz65sa-byte.github.io/bouzoukifret/)

## הפעלה מקומית

פתחו `index.html` בדפדפן (Chrome / Edge / Safari).

## פריסה ב-Vercel (מומלץ לקבוצות)

1. העלו את הריפו ל-GitHub
2. היכנסו ל-[vercel.com](https://vercel.com) → **Add New Project**
3. בחרו את הריפו `penia-master`
4. **Framework Preset:** Other (אין build — אתר סטטי)
5. **Deploy** — תוך דקה תקבלו קישור לשיתוף

## מה יש במשחק

### 3 משחקים

| משחק | שלבים | קלט |
|------|--------|-----|
| **מאסטר הפריטה** | 12 | מיקרופון / מקלדת ↓↑ / מגע |
| **מאסטר המודוסים** | 22 | מיקרофון (מומלץ) |
| **מאסטר האקורדים** | 18 זורם + 8 שירים + ספרייה | מיקרופון (מומלץ) |

- **מסך הכנה** — הסבר + גרף לימוד לפני כל שלב
- **גרף חי במשחק** — סריגים נעים עם הצליל/אקורד הבא (מודוסים ואקורדים)
- **משחק קצב** — חיצים / צלילים / אקורדים, ניקוד, קומבו, כוכבים
- **פרופילי שחקנים** — כל נגן בקבוצה עם שם ואווטאר
- **לוח תוצאות** — התחרות בין הנגנים
- **שיתוף ציון** — כפתור "שתף בקבוצה" לוואטסאפ
- **סטטיסטיקות קהילה** (אופציונלי) — Firebase

> **שימו לב:** מודוסים ואקורדים דורשים **מיקרופון** לציון. בלי mic אפשר לתרגל ויזואלית; פריטה עובדת גם במקלדת ובמגע.

## שליטה

| מכשיר | ↓ למטה | ↑ למעלה |
|--------|--------|--------|
| מקלדת | ↓ או J | ↑ או K |
| מגע | חצי תחתון של המסלול | חצי עליון |
| בוזוקי | פרטו על מיתר מושתק — המשחק שומע | |

כפתור **🎸/📱** במסך המשחק: מעבר בין מצב מיקרופון למצב הקשה (פריטה בלבד).

## סטטיסטיקות קהילה (Firebase — חינם)

1. צרו פרויקט ב-[Firebase Console](https://console.firebase.google.com)
2. הפעילו **Realtime Database** (במצב test לפיתוח)
3. העתיקו `config.example.js` → `config.js` והדביקו את הפרטים
4. במסך הבית יופיעו: **כמה נגנים** ו**כמה משחקים** בכל הקבוצות

> `config.js` לא עולה ל-Git — הגדירו אותו ב-Vercel Environment Variables או מקומית בלבד.

### כללי אבטחה מומלצים (Firebase Rules):

```json
{
  "rules": {
    "stats": {
      ".read": true,
      "players": { ".write": true },
      "games": { ".write": true }
    }
  }
}
```

## שיווק לקבוצות בוזוקי

- שלחו קישור + QR code לקבוצת הוואטסאפ
- בכל שיעור: כל נגן יוצר פרופיל → שלב → לוח תוצאות
- "שתף בקבוצה" מעתיק טקסט מוכן לוואטסאפ
